# 顔かくし（KAOKAKUSHI）

学級通信・学年通信・学校ブログ用の**顔ぼかしアプリ**です。
写真は**端末の中だけ**で処理され，ネットにもクラウドにも一切送信されません。

## 使い方

1. 「写真を選ぶ」をタップ（またはドラッグ＆ドロップ）
2. **自動モード**（初期状態）で顔と，名前が書かれた場所が見つかると自動でぼかしがかかります
3. 足りないところは道具（四角・丸・ブラシ）でなぞって追加
4. 「かくし方」から30種類のぼかし・モザイクを選択，「こさ」で強さを調整
5. 「保存」でJPEGまたはPNGとして端末に保存

### 自動モードと手動モード

- チェックを外すと**手動モード**になり，自動での顔さがしが止まります
- 自動モードのときにかかったぼかしは**そのまま残り**，手動で移動・変形・削除できます

### 名前・文字もかくす

名札・作品のネームカード・背景の掲示物など，**文字が書かれた場所**も自動でさがしてぼかします。

- 「文字の探し方」で**ひかえめ／ふつう／とことん探す**を切り替えられます
- 多く拾いすぎたときは「消す」で個別に外せます
- この検出はAIモデルを使わない画像処理なので，**追加のダウンロードも通信も発生しません**

### 選んだ範囲だけを調整

範囲をタップして選ぶと「**選んだ範囲**」のパネルが出ます。

- **大きさ**のスライダーで，その範囲だけ広げたり狭めたり
- 「かくし方」「こさ」も，選んでいる間はその範囲だけに反映されます
- 「削除」でその範囲だけ消去，「選択をやめる」で全体設定に戻ります

### 道具

| 道具 | できること |
|---|---|
| 四角 | ドラッグで四角い範囲を追加。タップで選択，角をつまんで変形 |
| 丸 | ドラッグで楕円の範囲を追加 |
| ブラシ | 指やマウスでなぞって範囲を追加 |
| 消す | 範囲をタップして削除 |
| 切り抜き | トリミング（自由／1:1／4:3／3:4／16:9／9:16） |

### 便利な操作

- ピンチ／ホイールで拡大，ダブルタップで戻る
- 範囲を選んでからぼかしの種類を変えると**その範囲だけ**変更
- 何も選ばずに変えると**すべての範囲**をまとめて変更
- 左上の矢印で元に戻す／やり直す

## プライバシーについて

- 画像処理はすべて**ブラウザの中（あなたの端末の中）**で完結します
- サーバーへのアップロードは一切行いません
- 顔認識のAIモデルもこのサイト内に同梱しており，外部CDNへの通信もありません
- 文字の検出はAIモデルを使わない古典的な画像処理なので，追加のダウンロードもありません
- 保存時にキャンバスで再エンコードするため，**位置情報などのExifは自動的に消去**されます
- オフラインでも動作します

## 対応形式

JPEG・PNG・HEIC／HEIF・WebP・TIFF・BMP・GIF・AVIF など（端末やブラウザによります）

保存形式はJPEGまたはPNGを選べます。

## 動作環境

PC・タブレット・スマートフォンのモダンブラウザ（Chrome，Edge，Safari，Firefox）。

初回だけ顔認識モデル（約6MB）の読み込みに少し時間がかかります。

## 技術メモ

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

- 顔検出：[@vladmandic/face-api](https://github.com/vladmandic/face-api)（SSD MobileNet v1 ＋ Tiny Face Detector）
- 文字検出：自前実装（形態学的勾配→Otsu二値化→方向別クロージング→連結成分の絞り込み）
- HEIC変換：[heic2any](https://github.com/alexcorvi/heic2any)
- TIFF読み込み：[UTIF.js](https://github.com/photopea/UTIF.js)
