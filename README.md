# モザイク先生

学級通信・学年通信・学校ブログのための，**顔と名前のかくしアプリ**です。
写真は**端末の中だけ**で処理され，ネットにもクラウドにも一切送信されません。

## 使い方

1. 「写真を選ぶ」をタップ（またはドラッグ＆ドロップ，**Ctrl+V で貼り付け**）
2. **顔**が自動で見つかり，ぼかしがかかります
3. 名札もかくしたいときは，文字のアイコンをオンにする
4. 足りないところは道具（ブラシ・四角・丸）で足す
5. かくし方（30種類）と，こさ（スライダー）を選ぶ
6. 右上の保存ボタンで，JPEGまたはPNGとして端末に保存（→「[保存について](#保存について)」）

画面の文字は最小限にしてあります。ボタンは長おし（PCではマウスを重ねる）で名前が出ます。

### 写真の開き方は3通り

| やり方 | どこでも |
|---|---|
| 「写真を選ぶ」をタップ | ホーム画面／カメラのボタン |
| ドラッグ＆ドロップ | 画面のどこでも |
| **Ctrl+V（Macは⌘+V）** | 画面のどこでも。**編集中の写真の上でも** |

Windowsの `Win+Shift+S` などでとったスクリーンショットは，
ファイルに保存しなくても，そのまま Ctrl+V で開けます。
編集中に貼ると，その写真と入れかわって，新しい写真の編集がはじまります。

なお Ctrl+V には，コピーした**範囲**を貼り付けるはたらきもあります。
どちらになるかは，**あとからコピーしたほう**が勝ちます。

- 範囲を Ctrl+C した直後の Ctrl+V → **範囲**が貼られる（前にとったスクショが残っていても）
- 新しくスクショをとったあとの Ctrl+V → **その写真**が開く

## 画面のボタン

### 上のバー

| ボタン | はたらき |
|---|---|
| ↶ ↷ | 元に戻す／やり直す（Ctrl+Z／Ctrl+Y） |
| カメラ | 別の写真を開く |
| ↓（青） | 保存 |

### 自動でさがす

| ボタン | はたらき |
|---|---|
| 顔のアイコン | 顔を自動でかくす（オン／オフ）**はじめからオン** |
| 文字のアイコン | 名札を自動でかくす（オン／オフ）**はじめはオフ** |
| 弱・中・強 | さがす強さ **はじめは弱** |
| ↻ | いまの設定でもう一度さがす |

- **弱**＝ひかえめ，**中**＝ふつう，**強**＝とことん探す
- はじめは**顔だけ**をかくす設定です。名札もかくしたいときは文字のアイコンをオンにします
- オフにすると，**自動でついたぶんだけ**が外れます。手で足したものや，複製したものは残ります

### 道具

| アイコン | できること |
|---|---|
| ブラシ | **なぞったところだけ**をかくす（太さはスライダーで調整） |
| 四角 | ドラッグで四角い範囲を追加 |
| 丸 | ドラッグで楕円の範囲を追加 |
| 消しゴム | 範囲をタップして削除 |
| 切り抜き | トリミング（自由／1:1／4:3／3:4／16:9／9:16） |

### 選んだ範囲

範囲をタップして選ぶと，青いバーが出ます。

- スライダーでその範囲だけ大きさを変える
- ゴミ箱でその範囲だけ削除，×で選択をやめる
- 選んでいる間は，かくし方とこさも**その範囲だけ**に効きます
- 何も選ばずに変えると**すべての範囲**がまとめて変わります

## 範囲の操作

### 回す

範囲を選ぶと，上に出るつまみをドラッグして回せます（四角と丸）。
**Shift**を押しながらだと15度きざみでそろいます。

### コピー・貼り付け・複製

| 操作 | はたらき |
|---|---|
| Ctrl+C → Ctrl+V | コピーして貼り付け（回転もそのまま） |
| Ctrl+X | 切り取り |
| Ctrl+D | その場で複製 |
| Delete / Backspace | 削除 |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Esc | 選択をやめる |

範囲の上で**右クリック**（スマホ・タブレットは**長おし**）すると，
複製・コピー・貼り付け・削除のメニューが出ます。
ブラウザの「名前を付けて保存」は出ません。

### そのほか

- ピンチ／ホイールで拡大，ダブルタップで戻る

## さがし方について

### 顔

正面だけでなく，**横顔**も見つけられるように，
元の画像・左右反転・重なりのあるタイル分割の複数の見方を組み合わせています。

### 名札

ねらいを**名札・ネームカード**にしぼってあります。
文字なら何でもかくすのではなく，「**名前が書かれた札**」らしいものだけを選びます。

- 苗字と名前が**分かれて**書かれていても，1つのまとまりとしてかくします
- 苗字の一文字目だけ，名前の一文字目だけ，といった**短いもの**も拾います
- 遠くに写っていて**粗い**名札も，解像度を変えて何度もさがすことで拾います
- 文字だけでなく，**カードのふちまで**広げてかくします
- この検出はAIモデルを使わない画像処理なので，**追加のダウンロードも通信も発生しません**

#### 「札らしさ」の見分け方

木の葉・砂利・れんが・服のしま模様・髪の毛は，輪郭だけ見ると文字とよく似ています。
そこで文字らしさに加えて，次の「札らしさ」を確かめています。

- 地の色が**広くて一色**である（紙やプレートだから）
- その上に，はっきり濃さのちがう印がのっている
- **明るい地に，暗い字**である（白い紙に黒で書く）
- 印は地に対して**少数派**である
- 書いてあるのが名前なので，**細長くなりすぎない**
- 写真全体から見ると**小さい**

さらに，**画面のうちかくす割合に上限**を設けてあります。
どんな写真でも画面全体がつぶれることはありません。

#### 限界

「名前かどうか」を字の意味から判断しているわけではありません。
白い紙に短く書かれた掲示物は，名札とまちがえて拾うことがあります。
逆に，模様の多い服の上にある小さすぎる名札は，拾えないことがあります。

多く拾いすぎたときは消しゴムで個別に外せます。
拾えなかったときは，強さを**中**や**強**に上げるか，道具で手で足してください。

## 保存について

保存のしかたは端末によって違うので，その端末に合った道を自動で選びます。

| 端末 | 押したあと出るもの | どこに入るか |
|---|---|---|
| iPhone・iPad | 共有シート | **「画像を保存」**を選ぶと**写真**に入る |
| PC・Chromebook・Windowsタブレット（Chrome／Edge） | 保存先を選ぶ窓 | 選んだフォルダ |
| Android・Firefox・Mac の Safari など | そのままダウンロード | ダウンロードのフォルダ |

- iPhone・iPadでは，共有シートの中の**「画像を保存」**まで進んではじめて写真に入ります。ここで「ファイルに保存」を選ぶと，写真ではなくファイルアプリに入ります
- Androidでも写真アプリに入れたいときは，保存ではなく**共有ボタン**から「フォトに保存」を選べます
- 上のどれも使えない古い端末では，画像がそのまま開きます。**長おし**して保存してください

保存ボタンを押した瞬間に渡せるよう，保存の窓を開けた時点で画像を先に作っています。
大きな写真で間に合わなかったときだけ「もう一度，保存を押してください」と出ます。

## プライバシーについて

- 画像処理はすべて**ブラウザの中（あなたの端末の中）**で完結します
- サーバーへのアップロードは一切行いません
- 顔認識のAIモデルもこのサイト内に同梱しており，外部CDNへの通信もありません
- 文字の検出はAIモデルを使わない古典的な画像処理なので，追加のダウンロードもありません
- 保存時にキャンバスで再エンコードするため，**位置情報などのExifは自動的に消去**されます
- 一度読みこめば，オフラインでも動作します

## 対応形式

JPEG・PNG・HEIC／HEIF・WebP・TIFF・BMP・GIF・AVIF など（端末やブラウザによります）

保存形式はJPEGまたはPNGを選べます。

## 動作環境

PC・タブレット・スマートフォンのモダンブラウザ（Chrome，Edge，Safari，Firefox）。

顔さがしは，写真を開くたびに**毎回**自動で走ります。
顔認識モデル（約6MB）の読み込みだけは，そのタブで最初の1回にまとまります。
2枚目からは読み込みがないぶん，すぐに始まります。

## 技術メモ

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

- 顔検出：[@vladmandic/face-api](https://github.com/vladmandic/face-api)（SSD MobileNet v1 ＋ Tiny Face Detector）
  - 元画像・鏡像・2×2タイルの多視点検出を IoU で統合
- 名札検出：自前実装（形態学的勾配→Otsu二値化→方向別クロージング（幅を2通り）→連結成分の絞り込み→行のまとめ→カードのふちへの拡張→「札らしさ」の検証→かくす割合の上限で打ち切り）
- HEIC変換：[heic2any](https://github.com/alexcorvi/heic2any)
- TIFF読み込み：[UTIF.js](https://github.com/photopea/UTIF.js)
